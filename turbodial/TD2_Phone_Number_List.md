# How to use this list {data-eyebrow="Start here"}

1. Find the number in its group.
2. Do the procedure for one number (Rollout Plan, Section 7). Use the values in the row.
3. Do the 4 tests (Rollout Plan, Section 8).
4. Tick each box. Write the date and your initials in "Done".

| Box | Meaning |
|---|---|
| **Route** | The inbound call route is ready. |
| **Added** | The settings are typed and the TD2 switches are on. |
| **In** | Test 1: a call in rings the correct person. |
| **Out** | Test 2: a call out shows the owner's number. |
| **TxO** | Test 3: a text out shows the owner's number. |
| **TxI** | Test 4: a text reply arrives in TD2. |

::: warning
**Not on this list:** the 30 PlusThis numbers and the 3 system numbers. Do not set them up in TD2.
:::
