# Procedure for one number {data-eyebrow="Section 8"}

1. Make sure that the inbound call route for the number is ready.
2. Go to Settings › TurboDial › Phone Numbers.
3. Find the number. Press Ctrl+F and type the last 4 digits.
4. Click the pencil on the row of the number.
5. Type the **Name** from the number list.
6. Set the **Owner** and **Forward SMS To** to the TD2 user of the person in the number list.
7. Set the **Inbound Call Route**.
8. Set **Public for Caller ID** and **Record inbound calls** from the number list.
9. Turn on "Use TurboDial 2.0 Voice".
10. Turn on "Use TurboDial 2.0 SMS".
11. Click **Apply**.
12. In the number list, record the date and your initials in "Number added".

::: warning
**Warning:** Do not click "Release Number". This action removes the number from the account permanently. Do not click "Add Phone Number". This action buys a new number.
:::

# Tests after each person {data-eyebrow="Section 10"}

Use a company test phone. Do not use the phone of a client.

| Test | Procedure | Pass condition |
|---|---|---|
| 1. Call in | Call the number from the test phone. | The TD2 of the correct person rings. |
| 2. No answer | Call the number again. Do not answer. | The call goes to the no-answer step in the number list. |
| 3. Call out | Call the test phone from TD2. | The test phone shows the number of the owner. |
| 4. Text out | Send a text to the test phone from TD2. | The test phone shows the number of the owner. |
| 5. Text in | Reply to the text from the test phone. | The reply arrives in TD2. |

If all 5 tests pass, record the date and your initials in "Done" in the number list.

# Undo procedure {data-eyebrow="Section 11"}

### When to start the undo procedure

- A call to a moved number does not ring a person.
- A call or text from TD2 shows an incorrect number, and you cannot correct it in 15 minutes.
- A text to a moved number does not arrive in TD2 in 15 minutes.

### Procedure

1. Change the inbound call route of the number. Send all calls to the office cell, (206) 300-1000.
2. Open the number in Settings › TurboDial › Phone Numbers.
3. Turn off "Use TurboDial 2.0 Voice".
4. Turn off "Use TurboDial 2.0 SMS".
5. Click **Apply**. The calls and texts go back to TD1.
6. Call the number from the test phone. Make sure that TD1 rings.
7. Record the number, the problem and the time in the number list.
8. Tell TurboDial support.
9. Stop the go-live for that group until the cause is known.

::: tip
**Note:** Do steps 1 to 5 in less than 5 minutes.
:::

# Stabilize and close (Nov 30–Dec 11) {data-eyebrow="Section 13"}

### Daily check at 8:30 AM

1. Get the TD2 Daily Calls Report for the previous day.
2. Make sure that each moved user has calls or texts in TD2.
3. If a moved user has no calls or texts, test that user's numbers (Section 10).
4. Look at the voicemail list. Make sure that each voicemail has an owner.
5. Fix each problem in one working day.

### Close criteria (December 11)

The sponsor closes the project when all these items are true:

1. All Events, Client Care and RM numbers are in TD2.
2. All moved numbers passed the 5 tests.
3. For 3 working days, no undo procedure was necessary.
4. No call or text went out from (253) 215-8426 through TD2.
5. Each user calls and texts from their own number.

### After the close

- Keep TD1 on as the record of old calls, voicemails and recordings.
- Do not cancel TD1 until TurboDial gives written confirmation of how to get the old records.
