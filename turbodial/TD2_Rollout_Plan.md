# Procedure for one number {data-eyebrow="Section 7"}

1. Make sure that the inbound call route for the number is ready.
2. Go to Settings › TurboDial › Phone Numbers.
3. Find the number. Press Ctrl+F and type the last 4 digits.
4. Click the pencil on the row of the number.
5. Type the **Name** from the number list.
6. Set the **Owner** and **Forward SMS To** from Section 3, Task 3.
7. Set the **Inbound Call Route**.
8. Set **Public for Caller ID** and **Record inbound calls** from the number list.
9. Turn on "Use TurboDial 2.0 Voice".
10. Turn on "Use TurboDial 2.0 SMS".
11. Click **Apply**. The changes are saved only when you click Apply.

::: warning
**Warning:** Do not click "Release Number". This action removes the number from the account permanently. Do not click "Add Phone Number". This action buys a new number.
:::

# Undo procedure {data-eyebrow="Section 9"}

Use this procedure only when a problem has no solution and needs research.

1. Open the number in Settings › TurboDial › Phone Numbers.
2. Turn off "Use TurboDial 2.0 Voice".
3. Turn off "Use TurboDial 2.0 SMS".
4. Click **Apply**. The calls and texts go back to TD1.
5. Call the number from the test phone. Make sure that TD1 rings.
